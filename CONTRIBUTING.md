# Cómo contribuir

1. Lee `AGENTS.md` (reglas del proyecto) y `docs/ARQUITECTURA.md`.
2. Crea una rama desde `main`: `feat/…`, `fix/…` o `chore/…`.
3. Para tareas habituales sigue la guía de `.claude/skills/<tarea>/SKILL.md` (sirve también sin IA).
4. Antes de subir: `npm run check`.
5. Abre un PR con la plantilla y explica qué probaste de verdad.

Los asistentes de IA leen `AGENTS.md` (Codex, Cursor), `CLAUDE.md` y `.claude/` (Claude Code) y `.github/copilot-instructions.md` (Copilot): todas apuntan a las mismas reglas.
